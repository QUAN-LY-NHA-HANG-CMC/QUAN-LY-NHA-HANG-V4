# Restaurant Management System

This repository contains the Sprint 1 project foundation. It is intentionally a scaffold, not a runnable application: there are no implemented API routes, user interfaces, authentication, authorization, database access, or sample business data.

## Structure

- `backend/` - reserved for the backend service.
- `frontend/` - reserved for the web client.
- `docs/` - API and Git collaboration conventions.
- `.env.example` - safe local configuration template; copy it to `.env` and replace placeholders when implementation begins.

## Development status

The backend and frontend technology choices and their application code have not yet been added. The conventions in `docs/` guide future work; they do not describe existing functionality.
